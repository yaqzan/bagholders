| Field | v35 (earlier) | v36 (after refresh) | Δ |
|---|---:|---:|---:|
| w_comp (weekly composite) | 65 | 42 | −23 |
| w_bias | +6.9 | −3.5 | −10.4 |
| w_mom (momentum) | +5.0 | −7.3 | −12.3 |

| ern_boost | +0.426 (lifts to 86) | None (52 disqualifies) | −11 effective |

A 6-point pre_boost shift can produce a 17-point overall swing. Practical impact: a position entered at score=86 (high-conviction call near earnings) reading 52 the next day looks like an algorithm flip-flop even when mechanically correct.
**Second case study (2026-05-13 VICR audit, kept):** VICR 2026-05-12 showed the same class outside the earnings-boost context. v54 persisted an 85 CALL score using the completed 2026-05-04 weekly row (`w_comp=68`, `w_adj=+14.0`); the v55/v58-era full recalc used the current 2026-05-11 partial-week row (`w_comp=58`, `w_adj=-1.2`) with the same daily component stack (`trend=100, bb=42, rsi=30, macd=70, stoch=9, X=50`), producing a non-signal near 61. Economic read: v54 overstated a fresh call on an already-extended stock; the lower recalc score was closer to the correct neutral/watchlist read.
