# Alpha Mining

Canonical agent-facing source docs for Trader alpha discovery and collaboration.

Load these before starting new scoring, portfolio, or miss-led mining work:

- `C:\Development\Trader\alpha_mining\NEW_LEADS.md`: ranked backlog across scoring, portfolio, validation, and ops leads.
- `C:\Development\Trader\alpha_mining\MISS_CANDIDATES.md`: score-miss candidate queue from harmful miss groupings, updated for resolved mechanisms.

Rules:

- Keep these files compact, ranked, and current.
- Move resolved or killed ideas out of the active queue with the artifact that resolved them.
- Preserve enough evidence paths for another agent to continue without replaying terminal history.
- Do not use these docs as permission to change `ALGORITHM_VERSION`; ship gates and deploy workflow still apply.
